# Changelog

Native package releases use `native-vVERSION` tags. Compatibility platform changes
continue to be adopted through full reviewed source pins. See
[GitHub releases](https://github.com/northcutted/ios-release-workflows/releases)
for package assets and provenance.

## Unreleased

- Consumer-first README, verified install instructions, focused signing/release/
  screenshot guides, and a Fastlane adoption guide.
- Public beta support/validation matrix with links to fixed hosted evidence.
- Descriptive native CLI help and distribution-version diagnostics.
- Native contributor commands and structured bug/adoption reports.

## 0.2.0-beta.1 — 2026-10-04

First published native beta: app discovery, QA, signing vaults, archive/export,
GitHub Actions, TestFlight/store operations, and release management. Published
macOS arm64/x86_64 and Linux x86_64 binaries include checksums and hosted provenance.
